# Power-Distribution-Design-and-Management

This repository contains notebooks for the analysis of power distribution systems with OpenDSS. 

The idea of using OpenDSS is to exploit the benefits of its analytical and solver engine such that large power distribution systems can be analyzed.

It is extremely difficult to find power distribution software tools that can perform analysis for real networks without having the need to buy expensive legacy software that most universities cannot afford to purchase even with the 'academic' discount. OpenDSS is a powerful tool that can be used. However, its interface requires a steep-learning curve that is not always possible to be taken for most utility engineers (especially in Ecuador). These engineers are used to utilize and manage legacy software that has been adopted few decades ago. This tradition makes it difficult to incorporate new tools or 'think outside the box'. Hence, my purpose with these notebooks is to provide a sample of what can be done with automation and the possibilities of building in the future an open-source platform based on OpenDSS that approximates to the legacy software environment that utilities engineer are used to.  

The OpenDSS idea came to mind after realizing that the Ecuadorian power distribution databases can be exported and, through the use of an interface, converted to the OpenDSS format. Then, it is plausible and possible to analyze the real networks and investigate further the impact of electric vehicles, distributed generation, etc., with modelling techniques we can actually build and understand without the need to depend on third party upgrades or contracts. Python can help in building the graphical platform and depict practically any kind of plot the user can think of. 

Maybe this endeavor is overrated, but I believe this is a real path!

There is still a long journey to go, but these small steps can inspire others to build 'trustable' open-source platforms that could one day surpass legacy software in the name of what many have called the 'democratization of knowledge'.  

The notebooks are described below.

* INGP1120_DistributionLoadFlow.ipynb: This notebook performs load flow of electrical distribution systems with OpenDSS. The database has been already obtained and debugged and the user must have a folder in his drive that contains all the .dss files required to use OpenDSS engine. The results and plotted in GIS style, that is, resembling the legacy software whose environment is strictly graphical. As most of utilities use GIS-based databases, this notebook can be used to read results in similar format.
* INGP1120_Distribution_ReliabilityAnalysis_static_v1.ipynb: This notebook performs reliability analysis of a distribution network. Component information requires declaring failure rates and repair times in order to obtain classical reliability indexes: SAIFI, SAIDI, CAIFI, CAIDI, ENS. In addition, the notebook also calculated and compares to the Ecuadorian reliability standard that uses two indexes: FMIK and TTIK.
* INGP1120_Distribution_VoltageRegulation_heuristic.ipynb: This notebook helps in determining candidate locations for regulator and capacitor banks to achieve a voltage regulation setpoint. It performs a heuristic analysis based on performance indicators per bus to identify voltage weaknesses and reactive deficiencies
